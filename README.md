# Boarding Pass Kiosks: Agent-Based Simulation in AnyLogic

Simulation course project, B.E. Industrial Engineering, Lebanese American
University

## Overview
A simulation study to find the ideal number of boarding pass kiosks for an
airport, so that passenger processing times are met. The models were built as
agent-based simulations in AnyLogic.

## What I did
- **Model development:** used AnyLogic to build agent-based models that
  simulate how many kiosks are needed to meet processing time targets
- **Results analysis:** worked with my team to analyze the simulation results
  and identify the key metrics for optimizing kiosk installations, with the
  aim of improving the airport's operational efficiency

## Approach
- Agent-based model of passengers arriving and using kiosks
- Scenarios with different numbers of kiosks

## Tools used
AnyLogic
